# PopX React App

A pixel-perfect implementation of the PopX mobile app UI built with React, Vite, Tailwind CSS, and React Router.

## Features

- Responsive mobile-first design
- React Router navigation
- Pixel-perfect UI based on Adobe XD design
- Desktop-centered mobile layout

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
